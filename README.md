# Instructions to run Expo App

1. Get into the correct repository by typing cd campus-spots.
2. Once you're there, you must type the following command: npx expo start. This will run the app. 
3. Then, you can scan the QR code to see the app on your phone, or open it in a web browser instead.
4. In the index.tsx file, which is located in src/app/, you can change the app's code.
